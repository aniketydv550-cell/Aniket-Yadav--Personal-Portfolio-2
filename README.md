# Aniket Yadav - Personal Portfolio

A sleek, responsive, and professional personal portfolio website built with pure HTML and CSS. This portfolio is designed to showcase my skills, projects, and professional background.

## 🌐 Live Website
**View the live site here: https://aniketydv550-cell.github.io/Aniket-Yadav--Personal-Portfolio-2/

## 🚀 Features
- **Modern & Professional UI**: Clean layout with a vibrant indigo primary theme and white background.
- **Fully Responsive**: Adapts seamlessly to mobile, tablet, and desktop screens.
- **Content Protection**: Includes basic anti-copy mechanisms (disables right-click and text selection) to protect images and text.
- **Interactive Animations**: Smooth hover effects on buttons, navigation links, and the profile picture for a premium feel.

## 🛠️ Technologies Used
- **HTML5**: Semantic structure.
- **CSS3**: Custom styling using CSS variables, Flexbox, Grid, and smooth transitions (No external frameworks used).

## 📂 Project Structure
- `index.html` - The main structure of the website, divided into About, Skills, Projects, and Contact sections.
- `styles.css` - Contains all custom styling rules, color palettes, and responsive media queries.
- `profile_pro.jpg` - The professional profile picture displayed on the site.

## 💻 How to Run Locally
1. Download or clone this repository to your local machine.
2. Simply double-click the `index.html` file to open it in any modern web browser.
3. *(Optional)* Use a local server like the "Live Server" extension in VS Code for live reloading.
